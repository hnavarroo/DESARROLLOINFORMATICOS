# Help Desk API REST & Sistema de Tickets

Este repositorio contiene la API REST para el sistema de Help Desk desarrollada con **Node.js**, **Express** y **PostgreSQL**.

---

## Requisitos Previos

- **Node.js** (v16 o superior)
- **PostgreSQL** (v14 o superior)
- **Git**

---
